## 🚀 如何运行前端

### 开发模式（推荐用于测试）

```bash
# 1. 进入前端目录
cd rasa/core/flow_editor/frontend

# 2. 安装依赖（第一次运行需要）
npm install

# 3. 启动开发服务器
npm run dev
```

开发服务器将在 `http://localhost:5173` 启动，支持热重载。

### 生产构建

```bash
# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

构建输出在 `dist/` 目录。

## 🔧 与后端集成

### 前端配置

前端已配置代理，自动将 API 请求转发到后端：

```typescript
// vite.config.ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:5005',  // Rasa 服务器
        changeOrigin: true,
      },
    },
  },
});
```

### 启动完整系统

**终端 1 - 启动 Rasa 后端：**
```bash
cd rasa
python -m rasa run --enable-api --port 5005
```

**终端 2 - 启动前端：**
```bash
cd rasa/core/flow_editor/frontend
npm run dev
```

然后在浏览器中打开 `http://localhost:5173`
